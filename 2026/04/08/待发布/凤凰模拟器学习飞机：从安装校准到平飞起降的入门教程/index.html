凤凰模拟器学习飞机：面向 CAAC 学习的固定翼入门教程

很多时候，不是你不会飞，而是你还没有把固定翼的方向感和操纵逻辑练到下意识。

写在前面

  • 这篇文章说的“学习飞机”，主要是指用凤凰模拟器练习遥控固定翼飞机的基础飞行，不是真人驾驶航空器。
  • 这篇内容更偏向CAAC 学习阶段的固定翼基础操纵认知，尤其适合已经会飞多旋翼、但准备补固定翼方向感和操纵逻辑的朋友。
  • 对于多旋翼手来说，最大的难点通常不是起飞本身，而是固定翼的持续前飞、不能悬停、机头朝向变化后左右感反转。
  • 本文重点放在“怎么练方向感、怎么建立固定翼杆感、怎么避免把多旋翼习惯带错到飞机上”，希望能帮你少走一些弯路。

一、为什么多旋翼手学固定翼前建议先用凤凰模拟器

如果你之前主要飞多旋翼，那么你已经有一定的遥控器操作基础，但固定翼和多旋翼的操纵逻辑并不是简单平移。

很多多旋翼手第一次接触固定翼，最容易犯的错误不是不会拉杆，而是下意识还在用“悬停思维”修飞机。多旋翼偏了，你还可以悬停后慢慢修；固定翼一旦拉远、转向、掉头，左右操作和视觉感受很容易打架，结果就是越修越乱。

凤凰模拟器的价值不在于把画面做得多炫，而在于它能让你反复练下面几件最基础也最关键的事：

  1. 把多旋翼的操作习惯切换成固定翼的操纵逻辑；
  2. 认识油门、升降、副翼、方向舵分别影响什么；
  3. 建立“飞机朝你飞来时，左右方向会反过来”的反应习惯；
  4. 在不炸真机的前提下反复练平飞、转弯、进场和降落；
  5. 先把手上的杆感练顺，再去适配后续 CAAC 学习和真机训练。

如果你本来就是多旋翼手，我的建议很简单：不要急着证明自己会飞，先把固定翼飞到“不慌”。

二、开始前需要准备什么

通常一套最基础的练习环境包括下面几样：

  1. 一台能稳定运行模拟器的电脑；
  2. 凤凰模拟器软件本体；
  3. 遥控器 + 对应训练线 / USB 适配器；
  4. 一点耐心，不要想着第一天就飞花式动作。

这里有个很重要的原则：尽量用你未来准备飞真机时会使用的遥控器来练。因为真正需要建立的是手感，而不是键盘操作习惯。用遥控器练，后面切到真机时迁移成本最低。

如果你一直飞的是Mode 2多旋翼遥控器，那么进入固定翼训练时，建议仍然先保持Mode 2，不要一边练飞机一边换杆型，不然会把问题混在一起。

三、凤凰模拟器的安装与遥控器校准

这一部分最容易被忽视，但如果校准没做好，后面练得越久越容易养成坏习惯。

1. 先确认遥控器是否被电脑识别

把训练线或 USB 适配器接好后，先确认系统已经识别到了控制设备。只要电脑能识别为游戏控制器或输入设备，后面一般就能进模拟器做映射。

如果电脑都没有识别到设备，先不要急着进模拟器折腾，优先检查下面几项：

  1. 数据线是否只是充电线；
  2. 驱动是否正常；
  3. 遥控器是否已经开机；
  4. USB 接口是否供电稳定。

2. 在模拟器里完成通道映射

进入凤凰模拟器后，找到遥控器设置或校准向导，按提示依次推动各个摇杆，让软件识别每个通道。

固定翼入门至少要确认下面四个主通道是对的：

  1. 油门 Throttle
  2. 副翼 Aileron
  3. 升降 Elevator
  4. 方向舵 Rudder

上面这张图默认按Mode 2绘制。对多旋翼手来说，最需要重新建立的是下面两个认知：

  1. 左手油门在固定翼里不是“拉高度”的直接控制，它更接近“给飞机保速度、保能量”；
  2. 右手副翼 + 升降是在控制飞机姿态，不是像多旋翼那样把机体“平移”到某个点。

如果通道方向反了，不要硬练，先在设置里把对应通道反向。一个简单检查方法是：

  1. 推油门，发动机转速应该上升；
  2. 拉升降，机头应该有上仰趋势；
  3. 副翼打左，飞机左翼应下压、右翼上抬；
  4. 方向舵打左，机头应有向左偏转趋势。

3. 一定要做摇杆中位和行程校准

新手很容易忽略中位漂移。中位不准时，你明明松杆了，飞机却还在偷偷偏航或者轻微抬头，练久了会误以为是自己技术差。

所以建议：

  1. 中位校准做一次；
  2. 四角行程打满一次；
  3. 确认松杆后通道回到稳定中位；
  4. 油门最低点和最高点都能被完整识别。

4. 新手参数尽量保守

如果模拟器里可以调机型灵敏度、舵量或 Expo，入门阶段不要设置得太激进。核心思路是：

  1. 舵量不要过大；
  2. Expo 可以适当加一点，让中位更柔和；
  3. 风速先设低；
  4. 不要一开始就上 3D 机或高速机。

四、把四个操纵量和飞机欧拉角先对上

如果你是为了 CAAC 学习补固定翼认知，这一节建议认真看。因为很多“飞着飞着就乱了”的根源，不是手不够快，而是脑子里没有建立清楚“我这一杆打下去，飞机到底会先变哪个姿态量”。

固定翼最常见的 3 个姿态角是：

  1. 滚转角 Roll / phi
  2. 俯仰角 Pitch / theta
  3. 偏航角 Yaw / psi

从入门和考试学习的角度，可以先建立下面这组最实用的映射：

  1. 副翼 -> 滚转 Roll(phi)：最直接影响飞机左右倾斜，飞机要不要转弯，第一步通常先看滚转有没有建立起来；
  2. 升降 -> 俯仰 Pitch(theta)：最直接影响机头抬起还是压下，也会连带影响速度趋势和升力状态；
  3. 方向舵 -> 偏航 Yaw(psi)：最直接影响机头左右偏转，地面滑跑、协调转弯、进近修正时都很常用；
  4. 油门 -> 速度/推力/总能量：这里最重要，油门不是欧拉角，它不直接等于滚转、俯仰、偏航，而是在给飞机“有没有足够能量飞下去”。

这一点对多旋翼手尤其关键，因为多旋翼里你对油门的直觉常常更接近“高度通道”；但在固定翼里，更准确的理解应该是：

  1. 油门主要决定飞机有没有足够速度和余量；
  2. 升降决定机头姿态变化；
  3. 油门和升降往往需要配合使用，不能分开死记。

你可以先记一个足够实用的口诀：

  1. 油门管能量
  2. 升降管俯仰
  3. 副翼管滚转
  4. 方向舵管偏航

如果把这层映射练进脑子里，后面平飞、转弯、进近和复飞都会顺很多。

五、面向 CAAC 学习阶段，新手第一架练习机怎么选

很多人一进模拟器就选战斗机、特技机或者看起来很帅的高速机，这基本等于给自己上难度。

建议优先选这类机型：

  1. 上单翼或下单翼中的初级教练机；
  2. 飞行速度偏慢、姿态稳定、抗失速能力更好的机型；
  3. 起落架正常、跑道起降更容易观察的模型。

尽量避开：

  1. 3D 特技机；
  2. 高速喷气机；
  3. 对舵量特别敏感的小型机；
  4. 一上来就练无起落架手抛机。

一句话总结：先求稳，再求帅。

六、练习场景怎么设置更适合 CAAC 学习阶段入门

场景设置直接决定你前期有没有信心。

我的建议是：

  1. 先选白天、视野开阔、带跑道的大场地；
  2. 天气尽量无风或微风；
  3. 视角先用第三人称或跟随视角，不要急着第一视角；
  4. 关闭不必要的复杂干扰因素。

新手最需要的是“看得清、反应得过来、修得回来”。如果一开始就把自己扔进复杂场地，训练效率通常很低。

七、推荐一条适合多旋翼手转固定翼的练习路径

这里不建议一上来就练完整起降流程，而是分阶段拆开。

第一阶段：先把“多旋翼思维”切成“固定翼思维”

这一步很关键。多旋翼很多时候是“发现偏了，修回原地”；固定翼更像是“保持速度，让它沿一条平顺轨迹飞过去”。

建议先记住这 4 个差异：

  1. 固定翼不能悬停，空中修正必须建立在有速度的前提下；
  2. 油门不是高度锁，油门主要影响能量和速度；
  3. 转弯不是单纯横移，而是滚转后带出航向变化；
  4. 一旦机头朝向变化，左右修正的体感会比多旋翼更容易混乱。

第二阶段：再认识四个舵面的作用

这一步不要急着飞远，核心是把每个动作和飞机姿态对应起来。

建议先在地面或低速状态观察：

  1. 油门大了，飞机会加速；
  2. 拉升降，机会抬头；
  3. 推升降，机会低头；
  4. 副翼控制左右滚转；
  5. 方向舵主要帮你修正航向，地面滑跑时尤其明显。

如果这一步没建立清楚，后面转弯和进场会一直乱。

第三阶段：先练“机头朝外”的平飞和转弯

机头朝外时，通常是固定翼新手最容易理解方向的阶段，因为你看到的左右和飞机本体的左右更接近一致。

先把这个阶段练顺，再去练更难的“机头朝你飞来”的反向修正，效率会高很多。

第四阶段：练平飞，不急着练花活

起飞后先不要想着转圈、翻滚、低空通场，先把平飞练稳。

平飞时重点看三件事：

  1. 飞机高度是不是稳定；
  2. 机翼是不是基本保持水平；
  3. 飞机有没有持续向一侧偏。

这里特别容易出现两个错误：

  1. 杆量过大，看到一点偏差就猛修；
  2. 修正之后不回杆，导致飞机又朝另一个方向偏过去。

所以平飞阶段要养成一个习惯：小杆修正，修完马上回中。

第五阶段：练大半径转弯

新手转弯最常见的问题，是只敢打副翼，不会补升降，也不会控制节奏。结果飞机一歪就掉高度，越掉越慌。

比较稳妥的做法是：

  1. 先轻打副翼，让飞机有一点倾斜；
  2. 视情况轻补一点升降，避免转弯时掉高；
  3. 转到目标航向前提前回杆，不要等转过头再猛修；
  4. 全程动作小一点，别用满杆。

建议先练左转，再练右转，然后练一个大矩形航线，而不是一上来绕很小的圈。

第六阶段：练“机头朝你飞来”的反向修正

这一关是很多固定翼新手真正的门槛。

当飞机朝你飞来的时候，你眼里的左和右，会和飞机本身的左右产生“反向感觉”。这时候最怕的不是不会飞，而是慌。

练这个动作时可以刻意做下面的训练：

  1. 让飞机远处掉头后朝自己平稳飞来；
  2. 只做很小的左右修正；
  3. 一旦方向乱了，立刻拉远、拉高、重新建立姿态；
  4. 不要低空硬扛。

这一阶段的目标不是飞得漂亮，而是先把“反向感”练出来。

如果你是多旋翼手，这里一定要强迫自己接受一个事实：飞机不是停在空中等你想明白再修。 一旦方向乱了，优先做的是拉高、拉远、减小动作，而不是像飞多旋翼那样原地抢修。

第七阶段：拆开练起飞和矩形航线

如果你后面是按 CAAC 学习思路练固定翼，那么不要把起飞、转弯、降落看成几个孤立动作，而要尽量开始建立“矩形航线”这个整体概念。

在模拟器里可以先按这个顺序练：

  1. 起飞后沿跑道方向稳定爬升；
  2. 到安全高度后转入侧风段；
  3. 再进入下风段，开始为后续进近做准备；
  4. 通过基线转向最后进近；
  5. 如果方向、速度或下滑不合适，立即复飞，不要硬落。

起飞不要当成一个动作，而要拆成三个动作：

  1. 滑跑保持方向；
  2. 达到速度后轻柔带杆离地；
  3. 离地后先稳住姿态，再慢慢爬升。

新手起飞常见错误：

  1. 油门一大就紧张，方向不修正，滑跑歪出跑道；
  2. 速度还不够就猛拉杆，结果失速；
  3. 刚离地就急着大幅爬升。

所以正确节奏应该是：跑直、加速、轻拉、稳住、再爬升。

第八阶段：拆开练降落

降落比起飞更考验节奏。不要觉得能飞起来就一定能落下来。

降落的核心不是“最后一下拉杆”，而是完整的进场管理：

  1. 提前对正跑道方向；
  2. 逐步收油，不要突然收死；
  3. 用姿态控制下降趋势，用油门控制整体能量；
  4. 接地前轻轻带一点升降，让飞机柔和落地。

新手最容易犯的两个错误是：

  1. 飞太快，冲过跑道；
  2. 飞太慢，提前失速栽下去。

所以你要练的不是“神之一拉”，而是“稳定进场”。

八、一个适合 CAAC 学习阶段的 7 天练习安排

如果你每天能拿出 30-45 分钟，可以先按这个节奏走：

第 1 天

  1. 完成安装、识别、通道映射和校准；
  2. 对照遥控器示意图熟悉四个主通道作用；
  3. 在地面和低速状态观察操纵反馈；
  4. 分清多旋翼和固定翼在油门、转弯、姿态控制上的区别。

第 2 天

  1. 只练起飞后的平飞；
  2. 不追求降落；
  3. 能把飞机拉到安全高度并稳定飞直。

第 3 天

  1. 练左转、右转；
  2. 练大半径掉头；
  3. 尝试飞出简单矩形航线。

第 4 天

  1. 重点练飞机朝自己飞来时的修正；
  2. 一旦乱了就拉高重来；
  3. 不做低空对头硬修。

第 5 天

  1. 单独练起飞；
  2. 反复做滑跑、离地、建立爬升；
  3. 保证每次离地动作都足够轻柔。

第 6 天

  1. 单独练进场和降落；
  2. 不求漂亮，先求能稳定对正跑道；
  3. 多练复飞，不要一次没落好就硬砸。

第 7 天

  1. 尝试完整飞一套流程；
  2. 从起飞到通场再到降落；
  3. 每次结束后回想自己到底错在“方向、速度、还是高度”。

九、多旋翼手练凤凰模拟器时最常见的几个坑

1. 只会猛打杆，不会小修正

固定翼不是靠暴力打杆救回来的。动作越大，姿态越乱。入门阶段最值钱的习惯就是“小幅输入，快速回中”。

2. 一紧张就把油门全收掉

很多人一慌就想“停下来”，但飞机不是汽车。空中全收油门如果速度不够，反而更容易掉下来。

对多旋翼手来说，这个错误特别常见，因为你之前已经习惯了“收点油门，先把位置稳住”。固定翼不是这个逻辑。

3. 一味盯着飞机，不看航线

你的视线应该更多放在飞机的飞行趋势和跑道关系上，而不是只盯机身本体。尤其是进场降落时，看航线比看机身更重要。

4. 总想一步到位

今天刚会起飞，明天就想低空通场，后天就想特技，这种节奏通常只会让自己反复受挫。模拟器最大的优势就是可以拆动作反复练，没有必要急。

5. 把方向舵当成多旋翼偏航去理解

多旋翼偏航时，机体可以原地改变朝向；固定翼里的方向舵更多是辅助修正航向、协调转弯和地面滑跑保持方向。两者名字看着像，但飞行效果完全不是一回事。

十、什么时候可以从模拟器过渡到后续真机或 CAAC 实操学习

至少满足下面几个条件再考虑进入下一阶段会更稳一点：

  1. 你已经能连续多次稳定起飞；
  2. 能在空中保持基本平飞和大半径转弯；
  3. 飞机朝你飞来时，不会立刻方向混乱；
  4. 能比较稳定地完成进场和落地；
  5. 知道什么时候应该复飞，而不是硬落。

如果这些动作在模拟器里还经常失控，那真机只会把错误放大。

十一、给多旋翼手补固定翼的几个实际建议

  1. 每次练习时间不用太长，但要尽量连续，宁可每天练半小时，也不要一周只猛练一次；
  2. 每次只给自己定一个小目标，比如今天只解决“起飞跑偏”，不要贪多；
  3. 练完以后回想一下，自己到底是“方向感问题”还是“节奏问题”；
  4. 真机和模拟器手感肯定不会完全一样，但基本操纵逻辑是能迁移的；
  5. 如果你本来飞多旋翼，一定要刻意提醒自己：固定翼先保速度，再谈姿态，再谈精细修正；
  6. 如果后续是为了 CAAC 学习，模拟器阶段先把方向感、平飞、转弯、进场意识打牢，比一味追求花哨动作更有意义。

写在最后

如果把学习飞固定翼这件事拆开看，本质上不是“你敢不敢飞”，而是“你能不能把最基础的几个动作练到不过脑子”。对于准备 CAAC 学习、又已经习惯多旋翼操作的人来说，凤凰模拟器最大的意义，就是先把固定翼方向感和固定翼操纵逻辑单独拎出来练顺。

真正靠谱的进步路径通常都不花哨：先校准设备，先认清遥控器和飞机方向，再练机头朝外平飞，练大转弯，练对头修正，最后再去磨起降。把这些动作一项项练顺，后面无论你是继续做 CAAC 学习，还是后续上真机，都会轻松很多。

（注：本文按固定翼入门训练思路整理，适合作为面向 CAAC 学习阶段、尤其是多旋翼转固定翼人群的博文初稿）
